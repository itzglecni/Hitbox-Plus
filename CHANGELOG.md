# Changelog

All notable changes to Hitbox+, newest first.

## 1.3.1 (2026-11-11)

* Moved the rainbow player list to its own card in the Players tab
* Fixed player name capitalisation
* Fixed `/hbteam remove` on your own name
* Fixed the empty name box suggesting a player
* Fixed hint text getting cut off

## 1.3.0 (2026-10-24)

* Added Players tab with Team Color
* Added `/hbteam` commands
* First public source release

## 1.2.0 (2026-10-13)

* Fixed hover color not matching real reach
* Fixed spear hits not being tracked
* Fixed hit color showing on missed hits
* Fixed left click in the config screen on 26.3

## 1.1.1 (2026-08-22)

* Fixed the reach bug
* Added Minecraft 26.3 support (2026-10-04)

## 1.1.0 (2026-06-12)

* Redesigned config screen
* Added RGB color picker with rainbow mode
* Added Minecraft 26.2 support (2026-06-22)

## 1.0.1 (2026-04-24)

* Added Minecraft 26.1, 26.1.1 and 26.1.2 support
* More features for 1.21.11

## 1.0.0 (2026-03-16)

* First release for Minecraft 1.21.11
